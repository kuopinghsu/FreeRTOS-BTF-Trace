Migration Heatmap shows where tasks move between cores. Open it from the activity rail and confirm the current scope before interpreting the result.

The corridor list summarizes movement from one core to another. The heatmap shows activity by core pair and time bin, while Chord mode presents the same movement as directional flows. Select a corridor or heatmap cell to locate the related activity on the timeline.

Use the investigation order shown by the report: load distribution first, then migration rate, ping-pong, dwell time, core-pair movement, and finally synchronization bounce. Lock Bounces Only helps separate ordinary migration from movement that occurs while a synchronization object is still held.
