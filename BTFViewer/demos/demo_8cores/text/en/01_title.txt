Welcome to BTFViewer. It is an AI-assisted tool for analyzing RTOS BTF traces. The basic rule is simple: find evidence first, then use AI to explain it. The desktop and web versions provide the same analysis features. In this demo, we use the web version and an eight-core sample trace.

This trace is 2.421 seconds long. It contains data from eight cores and 163 tasks. Several stress-test phases were recorded in one trace, so some warnings are expected. We will first inspect the timeline and follow the diagnostic steps in Statistics. We will verify each issue on the timeline before asking AI for help.
