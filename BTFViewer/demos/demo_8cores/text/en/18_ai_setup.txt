Ninth rung: AI, only after deterministic evidence. It never reads the raw BTF bytes. It only receives the structured Analysis Findings for the current Statistics scope, plus the span and core count. If Statistics is empty or scoped to the wrong window, the model will sound confident about the wrong thing. We already built the findings by hand — now connect an endpoint. Open Settings, AI. Tick Enable AI Assistant. Choose Google Gemini. Prefer a rolling model name such as gemini-flash-lite-latest. Paste your Gemini API key from Google AI Studio. Leave Auto-apply off so we can show Apply and Skip on tool cards. Click Test connection. When Test succeeds, save Settings. On the AI bar, Language sets the reply language. Templates sit above the conversation. Ask sends the box. Command-enter or control-enter is the shortcut. Stop cancels. Clear wipes the log so an old answer cannot colour the next one.
