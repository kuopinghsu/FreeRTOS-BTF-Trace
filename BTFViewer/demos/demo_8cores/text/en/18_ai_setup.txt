Ninth rung: AI, only after the timeline and Statistics already agree. The assistant never reads the raw B-T-F bytes. It only sees Analysis Findings and Statistics for the current scope — plus span and core count. If that scope is wrong, it will sound confident about the wrong window.

Open Settings, then AI. Tick Enable AI Assistant. This recording uses Google Gemini, model gemini three point one flash-lite, as the example. Paste a Gemini A-P-I key, click Test connection, then save. Local Ollama is fine too; it needs no key. Leave Auto-apply off so you can Apply or Skip when the model wants to move the view.

Every run can differ — another model, another day, or a different scope will change the tools, the wording, and the timestamps. Treat this clip as one worked example, not a script the assistant must repeat.

The AI tab is the investigation surface. You will see a stepper: Triage, Scope, Investigate, Verify, Experiment, Compare. An empty log shows Start Investigation. Language sets the reply language. Ask sends the box. Command-enter or control-enter is the shortcut. Stop cancels. Clear removes chat replies; the usage meter and investigation evidence stay.
