Step 7: check whether execution follows the firmware configuration.

Open Core Affinity. Mask is the set of cores a task is allowed to use. Observed Cores is where the task actually ran. Violations lists any core outside the mask. In this trace several affinity tasks ran on a core their mask does not permit, so the Violations column is not empty. Select a task with a violation and confirm it on the timeline before you treat it as a firmware bug rather than a test that sets the mask on purpose.

Next open Task Lifecycle. Tasks SR0 through SR3 each show four suspends and four resumes. Select SR0 and confirm it never runs between a suspend and its matching resume. Runs counts scheduler dispatches, so it can be much higher than four; that is normal.

You can set deadline thresholds under Settings, Display, Analysis thresholds. The values are in nanoseconds.
