Step 7: check whether execution matches the configured behavior.

Core Affinity compares the cores a task is allowed to use with the cores where it actually ran. If the Violations column is not empty, select the task and confirm the event on the timeline before deciding whether it is a firmware problem or intentional test behavior.

Task Lifecycle summarizes events such as suspend and resume. Use it to verify that a task does not execute during a period when it should remain suspended.

Deadline thresholds can be configured under Settings, Display, Analysis thresholds. A threshold helps BTFViewer flag suspicious timing, but the trace evidence is still needed to explain the cause.
