This file has eight cores, about thirty-one thousand run segments, and extra instrumentation for priority changes, sync objects such as mutexes and queues, and timed intervals. So mutex pairing and priority inheritance will show real data, not empty tables. One caution: this file stitches several test phases together. A warning on the full trace is a clue to investigate — not automatically a product bug — until you limit the view to one phase.
