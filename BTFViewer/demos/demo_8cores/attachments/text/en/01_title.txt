Welcome to BTFViewer, an AI-assisted tool for analyzing RTOS BTF traces. The workflow is simple: find the evidence first, then use AI to help explain it. The desktop and web versions provide the same analysis features. In this demo, we use the web version with an eight-core sample trace.

The trace is 2.521 seconds long and contains eight cores and 163 tasks. It combines several stress-test phases, so warnings are expected. We will first understand the timeline, then follow the Statistics findings, verify important evidence on the timeline, and only then use AI to investigate further.
